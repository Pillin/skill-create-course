# Facilitation Guide Reference

## Purpose

Defines the standard for `facilitation-guide.md` at the root level of each course. This file is the mentor's complete operating manual.

---

## Required sections

### Cómo usar este curso
General orientation: what the package contains, how to navigate it, what to read first.

### Rol de la mentora
What the mentor's role is — and what it is not. Key distinction: not a teacher who delivers content, but a guide who scaffolds thinking. Specific behaviors:
- Ask questions before giving answers.
- Let students make mistakes and accompany the error as part of learning.
- Celebrate process, not just correct results.
- Be honest when something is hard: "Esto es complejo, y tiene sentido que tome tiempo."
- Never infantilize. Use specific acknowledgment, not empty praise.

### Principios pedagógicos
Plain-language explanation of: active learning, UDL/accessibility, gender-aware approach, socioemotional learning, progression and continuity. Not academic definitions — practical guidance.

### Cómo preparar cada clase
Step-by-step: read the overview, complete the checklist, prepare slides, load Kahoot, verify platform access, confirm any logistics.

### Cómo usar las slides
What the slides file is and is not. How to convert it to a presentation tool. How to use the speaker script. Principles: high contrast, low text, live coding during demos.

### Cómo usar Kahoot
The Kahoot is a discussion tool, not a grading tool. Always discuss each answer. The explanation after a wrong answer is more valuable than the score.

### Cómo guiar ejercicios en la plataforma
Platform-specific guidance (Dodona, OmegaUp, etc.): how to introduce the platform, how to read error messages with students (not for them), how to use the auto-judge as a teaching tool.

### Cómo acompañar errores comunes
The most common errors in this type of course and how to handle them without taking over the student's problem-solving. Include a "first response" protocol: before explaining, ask "¿Qué te está diciendo el sistema?"

### Cómo cuidar el tono
Specific language guidance:
- Avoid diminutives that infantilize technical concepts.
- Name difficulty directly.
- Use feminine forms as default.
- Avoid "¡Muy bien!" — use specific acknowledgment.
- When a student gives up: "Tiene sentido que esto cueste. Sigamos."

### Adaptaciones para modalidad híbrida
What changes when some students are remote: screen sharing for live coding, chat for Kahoot participation, platform access is the same.

### Recomendaciones de cierre y reflexión
How to close each class in the last 5 minutes: open question, naming the day's progress, bridge to the next class.

### Sesión de Bienvenida
Full facilitation guide for the opening session:
- Purpose.
- Suggested structure with block-by-block timing.
- Materials needed.
- Tone notes.

### Ceremonia de cierre
Full facilitation guide for the closing ceremony:
- Purpose.
- Suggested structure with block-by-block timing.
- Tone notes.

---

## Tone

The facilitation guide is written directly to the mentor. Use second person ("tu rol", "sé directa"). Practical and specific — no academic abstractions.
