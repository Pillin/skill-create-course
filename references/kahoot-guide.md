# Kahoot Guide

## Purpose

`02-kahoot.md` is the consolidation block of each class. It is a discussion tool, not a grading instrument.

---

## Minimum count

- **Minimum 10 questions per class.** 11 is standard.

---

## Mandatory question types

Every Kahoot must include:
- At least one question about the **STEAM woman** of the class.
- For classes with an inspirational talk: at least one question about the talk content.
- At least one question at the advanced/challenge level.
- At least one true/false question (fast, accessible, good for warm-up or wind-down).

---

## Per-question structure

```
## Question NN
- **Type:** Selección múltiple / Verdadero-Falso
- **Difficulty:** Básico / Intermedio / Avanzado
- **Time:** NN seg
- **Question:** [Question text]
- **Options:** A) ... B) ... C) ... ✓ D) ...
- **Correct answer:** [Letter]
- **Explanation:** [Why this is correct — used after showing the answer]
- **Learning objective:** [Optional — which objective this checks]
```

---

## Difficulty distribution

| Difficulty | Proportion | Time |
|------------|------------|------|
| Básico | ~40% | 15–20 sec |
| Intermedio | ~40% | 25–30 sec |
| Avanzado | ~20% | 35 sec |

---

## Facilitation standard

The explanation field matters more than the correct answer. After each question, the mentor spends 30–60 seconds on the explanation — especially when there are wrong answers. The Kahoot is a conversation starter, not a score tracker.

---

## Language

Questions in Spanish. Code snippets in C++ (or the relevant language) within the question text. Keep question wording unambiguous — no trick questions.
