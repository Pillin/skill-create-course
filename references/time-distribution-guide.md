# Time Distribution Guide

## Purpose

Defines the standard time distributions for each session type, and explains how to handle ambiguity when the user specifies duration.

---

## Clarifying time during the interview

Time distribution is one of the most common sources of ambiguity. Always confirm:

1. **Total session duration** (e.g., 3 hours = 180 minutes).
2. **What blocks it includes** — and whether Kahoot is a separate block or embedded in another.
3. **For sessions with special blocks** (inspirational talk, Demo Day): which blocks are compressed and by how much.

**Common ambiguous input:**
> "1.5 hr de cátedra y 1.5 de ejercicios, con 15 min de Kahoot"

This means: 3 hours total. Kahoot is carved from those 3 hours, not additional. The 15 minutes comes from the practice block or from the lecture block — confirm which.

**How to resolve:** propose the distribution below and ask for confirmation before proceeding.

## Standard distributions

### Standard class (no special block)

| Block | Activity | Duration |
|-------|----------|----------|
| Apertura | Connection to previous class, prior knowledge activation | 10 min |
| Cátedra | Lecture + live demos | 50 min |
| Kahoot | Consolidation | 15 min |
| Pausa | Break | 10 min |
| Práctica guiada | First exercises with mentor support | 30 min |
| Práctica autónoma | Independent exercises on platform | 45 min |
| Cierre | STEAM woman, reflection, bridge to next class | 20 min |
| **Total** | | **180 min** |

### Class with 1-hour inspirational talk

| Block | Activity | Duration |
|-------|----------|----------|
| Apertura | Connection to previous class | 10 min |
| Cátedra comprimida | Compressed lecture | 30 min |
| Charla inspiracional | External guest talk (45 min) + Q&A (10 min) + closing (5 min) | 60 min |
| Kahoot | Consolidation (content + talk reflection) | 15 min |
| Pausa | Break | 5 min |
| Práctica guiada + autónoma | Exercises (combined, no full guided block) | 45 min |
| Cierre | Reflection, bridge to next class | 15 min |
| **Total** | | **180 min** |

### Demo Day / Closing ceremony (typical)

| Block | Activity | Duration |
|-------|----------|----------|
| Apertura institucional | Opening words | 15 min |
| Conversatorio | Guided round: "What can you do today that you couldn't 10 weeks ago?" | 30 min |
| Muestra de trabajo | Each student shares one exercise or project | 30 min |
| Palabras de cierre | Mentor speaks about the group, not individuals | 10 min |
| Entrega de diplomas | Institutional ceremony | 30 min |
| Fotografía y cierre libre | — | 25 min |
| **Total** | | **140 min** (adjust to actual duration) |

## Adjusting for different total durations

If the course uses a different total duration (e.g., 2 hours or 4 hours), scale the blocks proportionally while preserving the minimum viable blocks:

- **Always keep:** Apertura (10 min), Kahoot (15 min), Reflexión ejercicio (8 min), Cierre (10 min).
- **Scale:** Lecture and practice blocks.
- **Never remove:** The reflection exercise (Exercise 10) and the closing bridge.

---

## Recording the distribution

Once confirmed, document the exact distribution in `course-requirements.md` under "Datos generales" and again in `main-plan.md` under "Distribución del tiempo por tipo de sesión." Every class file (`01-slides.md`) should include the confirmed distribution in its header.
