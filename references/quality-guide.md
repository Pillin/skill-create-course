# Quality Check Guide

## Purpose

`07-quality-check.md` verifies that the class files meet all Niñas Pro standards. It can also serve as a post-delivery reflection log.

---

## Required verification categories

### Alineación
- [ ] The class aligns with `main-plan.md` for this session (title, content, STEAM woman, session type).
- [ ] Connects explicitly to the previous session.
- [ ] Connects explicitly to the next session.
- [ ] Content difficulty is appropriate for the target age and prior knowledge level.

### Bloom's Taxonomy
- [ ] Learning objectives use observable-action verbs (define, implement, identify, design — not "understand" or "know").
- [ ] Objectives span the appropriate Bloom's levels for this point in the course arc.
- [ ] Exercises cover at least three Bloom's levels (warm-up 1–2, core 3–4, challenge 5–6).
- [ ] Kahoot questions are labeled by difficulty and map to the correct Bloom's level.

### 5E Model
- [ ] **Engage:** The opening activates prior knowledge and creates curiosity before the explanation starts.
- [ ] **Explore:** There is at least one moment where students encounter the new concept before it is formally explained (demo, broken example, guided observation).
- [ ] **Explain:** The lecture introduces concepts formally, with vocabulary and examples.
- [ ] **Elaborate:** Exercises require students to apply and extend understanding in new contexts.
- [ ] **Evaluate:** Kahoot + Exercise 10 (written reflection) close the learning loop.
- [ ] Slides include `**5E phase:**` labels for each slide.

### Universal Design for Learning (DUA)
- [ ] **Representation:** Instructions delivered both verbally and in writing. Reference card specified or confirmed not needed for this class.
- [ ] **Action & Expression:** Manual tracing included in at least one exercise (programming/algorithm courses). Three exercise levels present. Written reflection (Exercise 10) present.
- [ ] **Engagement:** Real-world connection present. STEAM woman integrated meaningfully. Error normalization present in lecture script.

### Slides (.pptx)
- [ ] `01-slides.md` is complete with all required fields per slide (visible content, speaker script, estimated time, Bloom's level, 5E phase).
- [ ] `01-slides.pptx` generated with Niñas Pro brand (colors, fonts, logo, template).
- [ ] Speaker notes in `.pptx` match the script in `01-slides.md`.
- [ ] Code blocks readable at projector size (minimum 20pt monospace).
- [ ] WCAG AA contrast met for all text elements.

### Mandatory materials
- [ ] Kahoot: minimum 10 questions. Each has an explanation field.
- [ ] Exercises: minimum 10 items. Each has a mentor solution.
- [ ] Formative rubric 1–10 at end of exercises file, referencing Bloom's levels.
- [ ] Glossary: minimum 8 terms with full structure.
- [ ] STEAM woman: real, verifiable, with at least one verified source URL or academic citation.
- [ ] Preparation checklist: complete with logistics and pedagogy note.

### Enfoque Niñas Pro
- [ ] Language is non-infantilizing, rigorous, and warm.
- [ ] Gender perspective applied specifically (STEAM woman slide + Kahoot question, feminine default forms, non-stereotyped exercise contexts).
- [ ] UDL adaptations are specific — not generic ("se aplicó DUA" is not sufficient; name what was done).

### Sources
- [ ] No invented sources.
- [ ] STEAM woman sources are real URLs or verifiable academic citations.
- [ ] All references use APA 7 format.

---

## Post-delivery use

After the class is delivered, the mentor can use `07-quality-check.md` as a reflection log:
- What worked well.
- What did not work.
- What to adjust for the next delivery.
- Any student feedback worth capturing.
