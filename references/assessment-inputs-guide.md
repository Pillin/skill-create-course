# Assessment Inputs Guide

## Purpose

`assessment-inputs.md` is a handoff document to a separate evaluation skill. It does not contain evaluations, quizzes, or rubrics. It provides the structured inputs that another skill needs to generate assessments.

---

## Per-class structure

For each class, include one clearly labeled section. Use consistent headings:

```
### Clase NN — [Class title]

- **Objetivos de aprendizaje:** [Bulleted list, same as in 00-class-overview.md]
- **Conceptos clave:** [Bulleted list of terms covered]
- **Habilidades esperadas:** [What a student who completed this class can do]
- **Errores frecuentes:** [2–3 most common mistakes observed or anticipated]
- **Dificultad esperada:** [Low / Medium / High, with a brief justification]
- **Evidencias observables durante la clase:** [What a mentor sees when a student is achieving the objectives]
```

---

## What not to include

- No quiz questions.
- No rubric descriptions.
- No sample answers.
- No summative evaluation criteria.

Those belong in a separate evaluation skill.

---

## Scope

Cover all 10 (or N) content classes. Do not include entries for the Bienvenida or Ceremonia de cierre — those are facilitation events, not learning sessions with assessable objectives.
