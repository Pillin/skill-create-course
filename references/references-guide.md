# References Guide

## Purpose

Defines the standard for `references.md` at the root level of each course. This file consolidates all bibliographic sources used across the course in APA 7 format.

---

## Required categories

Organize sources under these headings (omit empty categories):

### Libros y capítulos
Academic books, textbooks, and book chapters.

### Artículos académicos
Peer-reviewed articles and conference papers.

### Documentación oficial y recursos técnicos
Official documentation (language specs, platform docs), official organization publications.

### Recursos educativos y divulgativos confiables
Reputable educational platforms (CS50, Khan Academy, etc.), platforms used in the course (Dodona, OmegaUp, Codeforces, etc.), vetted online resources.

### Fuentes para mujeres STEAM destacadas
One entry per STEAM woman featured in the course. Each entry must include at least one verifiable source. Acceptable: institutional biographies, academic citations, reputable journalism (BBC, Smithsonian, IEEE, ACM), TED talks, official award pages (Turing Award, Presidential Medal of Freedom, etc.).

### Marcos pedagógicos
Pedagogical frameworks cited or applied (Bloom's taxonomy, UDL guidelines, PBL research, etc.).

---

## APA 7 rules to enforce

- Books: Author, A. A. (Year). *Title in italics*. Publisher.
- Articles: Author, A. A. (Year). Article title. *Journal Name in Italics*, *volume*(issue), pages. https://doi.org/xxxx
- Web resources: Organization. (Year). *Title*. Retrieved [date], from URL
- Always include DOI or URL when available.
- If a source cannot be verified, do not include it.

---

## What not to include

- Sources that were consulted but not directly cited.
- Invented or hallucinated citations.
- Social media posts unless officially archived.
- Wikipedia as a primary source (can be a discovery tool, but the cited source should be the original).

---

## Update protocol

Add a new entry to `references.md` every time a new source is cited in any course file. The references file is a living document during course generation.
